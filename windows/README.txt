Hearth for Windows
==================

Русский
-------
1. Распакуйте эту папку куда удобно (например, в «Документы»).
2. Дважды щёлкните Hearth.vbs — Hearth откроется в окне Microsoft Edge.
   Если Windows спросит про доступ к сети для node.exe, можно разрешить только частные сети.
3. Чтобы значок был на рабочем столе, один раз запустите Make-Desktop-Shortcut.vbs.
4. На странице «Модели» скачайте движок (для видеокарт Radeon Hearth сам выберет Vulkan) и модель.
5. Остановить Hearth: Настройки → Выйти, или Stop-Hearth.vbs.
6. Чтобы боты работали и после перезагрузки: Настройки → Этот компьютер → «Запускать вместе с Windows».
   Там же «Не давать компьютеру засыпать» (по умолчанию — пока работают боты или модель).

Если что-то не запускается, откройте «Hearth (with console).bat»: в окне будет видно, что происходит.
Данные (модели, чаты, настройки, плагины) лежат в %LOCALAPPDATA%\Hearth.
Обновление: остановите Hearth (Stop-Hearth.vbs) и замените папку Hearth новой — данные останутся.

English
-------
1. Unzip this folder anywhere (for example Documents).
2. Double-click Hearth.vbs. Hearth opens in a Microsoft Edge app window.
   If Windows asks about network access for node.exe, allowing private networks is enough.
3. For a desktop icon, run Make-Desktop-Shortcut.vbs once.
4. On the Models page, download the engine (for Radeon cards Hearth picks Vulkan) and a model.
5. To stop Hearth: Settings > Quit, or Stop-Hearth.vbs.
6. For bots to keep working after a restart: Settings > This computer > Start with Windows.
   There too: Keep the computer awake (by default while bots or the model work).

If something doesn't start, open "Hearth (with console).bat" to see what it is doing.
Your data (models, chats, settings, plugins) lives in %LOCALAPPDATA%\Hearth.
To update: stop Hearth (Stop-Hearth.vbs) and replace the Hearth folder with the new one; your data stays.
