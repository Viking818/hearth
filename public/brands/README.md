# Logos of the connector directory

Shown next to each service in Customize → Connectors, so it is easy to recognize. The logos and names are trademarks
of their owners; Hearth uses them only to name the service and is not affiliated with or endorsed by them.

- `*.svg`: from Simple Icons 16.37.0 (https://simpleicons.org, CC0 1.0), filled with each brand's colour; light
  colours get a tile of that colour with a dark mark. Mercury and ShipBob are the icons from their own sites.
- `*.png`: each service's own site icon, 128 px.
